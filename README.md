## Origin

Reimplementation of a 2017 eYSIP project, "Formation Control of Multiple
Swarm Robots" (8 Spark V robots, ArUco-marker overhead-camera localization,
centralized master-slave control over XBee). No original code is reused;
this is a fresh ROS 2 + CoppeliaSim build inspired by that architecture.

## Stack

- Ubuntu, ROS 2 Jazzy
- CoppeliaSim (ZeroMQ Remote API)
- Python 3.12 (.venv)
